プライバシーポリシー

制定日: 2026年11月25日

友田 陽大（以下「当方」）は、iPhone アプリ「ヒヅケ」（以下「本アプリ」）で扱う情報について、次のとおり定めます。

1. 要約

  • 本アプリは、サーバーを持ちません。アカウントの作成も、広告も、利用者の追跡もありません。
  • 写真・サムネイル・ファイル名・撮影場所は、端末の外へ送りません。
  • 利用統計とクラッシュレポートは、利用者が同意したときだけ送ります。同意は、いつでもアプリ内で取り消せます。

2. 端末の中だけで扱う情報

  • カメラ: 撮影のために使います。映像と撮った写真は、この iPhone の中で現像します。
  • 写真ライブラリ: 現像した写真を「追加」するためだけに使います。ライブラリの写真を読み取りません。「写真から読み込む」（有料）は、iOS の写真ピッカーで利用者が選んだ写真だけを受け取ります。
  • 元画像: 再現像のために、撮影した元の写真をこの iPhone の中に残せます（設定で「すべて」「最近の 100 枚」「なし」を選べます）。端末の外へ送らず、iCloud バックアップの対象外です。アプリの削除で消えます。
  • 撮影の記録・設定・同意の選択: この iPhone の中に保存します。

3. 送るかどうかの選択（利用統計とクラッシュレポート）

初回の画面のスイッチと、「設定」>「プライバシー」の「利用統計を共有」「クラッシュレポートを送信」で、それぞれ別々に選べます。初期値はオフです。同意するまで、どちらも送りません。オフにすると、その場で送信を止め、端末に残る未送信のデータと匿名の ID を消します。

同意した場合に送る情報は、次のとおりです。

  • 利用統計: 利用統計の送信の仕組み（PostHog、米国）は本アプリに備わっていますが、バージョン 1.0 では有効にしていません。有効にする版では、あらかじめ決めた種類の出来事（コードと数のまとまり、はい/いいえだけ）に限り、同意した方の分だけを送ります。
  • クラッシュレポート: 異常終了の種類と原因の場所（関数名）、アプリの版、iOS の版、端末の機種、メモリや温度の状態、インストールごとのランダムな ID。送り先は Sentry（米国）。

次のものは、同意の有無にかかわらず送りません: 写真とそのサムネイル、写っているもの、ファイル名とパス、位置情報、写真ライブラリの識別子、空き容量の値、メールアドレスなどの連絡先、画面の記録。

通信の仕組み上、送り先には端末の IP アドレスが届きますが、当方は IP アドレスや位置を保存・利用しない設定にしています。広告や、他社のアプリ・サイトをまたいだ追跡には使いません。

4. 利用目的と保存期間

クラッシュレポートは、不具合の原因の調査のためだけに使います。保存期間は、Sentry で 90 日を上限とします（利用統計を有効にする版では、PostHog で 1 年を上限とします）。第三者への販売や、広告目的での提供はしません。

5. 購入

「すべてのフィルム」の購入は Apple の App Store が処理します。お支払いの情報は当方に届きません。当方は、購入が有効かどうかを、端末上の App Store の検証済みの取引だけで判断します。

6. 利用者の権利

当方は、利用者を特定できる情報を保有しません。インストールごとのランダムな ID は、アプリ内で送信をオフにすると消え、次にオンにすると別の ID になります。ご不明な点は、下の連絡先へどうぞ。EU/EEA・英国の方は、同意の取り消しをいつでも行えます（上の 3.）。

7. お子様

本アプリは、年齢を問わず、個人を特定できる情報を求めません。

8. 変更

この方針を変えるときは、このページを更新し、制定日の下に改定日を書きます。利用者に不利な変更や、送る情報の追加は、アプリ内で改めて同意を求めます。
